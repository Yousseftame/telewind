# TeleWind Electronics – Frontend Application

This repository contains the frontend codebase for **TeleWind Electronics**, showcasing defense-grade RF, radar, electronic warfare, and intelligent electronic systems.

---

## 🚀 Tech Stack

The project is built using modern frontend technologies:

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **shadcn/ui**

---

## 📦 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or later recommended)
- npm

You can manage Node versions using **nvm** if needed.

---

### Installation

```sh
# Clone the repository
git clone <REPOSITORY_URL>

# Navigate to the project directory
cd <PROJECT_NAME>

# Install dependencies
npm install
